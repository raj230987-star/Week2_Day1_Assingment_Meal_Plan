# 🥗 7-Day South Indian Vegetarian Meal Plan – Prompt Engineering Project

## 📌 Project Overview

This project demonstrates how to design a reusable and structured AI prompt to generate a healthy, balanced, and affordable 7-day South Indian vegetarian meal plan for individuals working towards gradual and sustainable weight loss.

Instead of simply asking AI to generate a diet plan, this project uses a well-structured prompt that defines the AI's role, user profile, food preferences, dietary restrictions, health guidelines, and expected output format.

The prompt can be reused for different individuals by changing their personal details.

## 🎯 Problem Statement

A simple request such as "Give me a diet plan" often produces generic results that may not match an individual's age, weight, height, activity level, food preferences, or dietary requirements.

The objective of this project is to solve this problem by creating a reusable prompt that consistently generates personalised and structured South Indian vegetarian meal plans.

## 💡 Project Objectives

- Develop a reusable AI prompt for meal planning.
- Generate a complete 7-day South Indian vegetarian meal plan.
- Personalise meal recommendations based on user information.
- Include traditional and locally available South Indian foods.
- Encourage healthy eating and sustainable weight management.
- Generate a weekly grocery list and daily healthy habits.
- Demonstrate practical Prompt Engineering techniques.

## 🧠 Prompt Engineering Framework

The project follows a structured prompt engineering approach:

| Component | Description |
|---|---|
| Role | Defines the AI as a nutrition-aware meal-planning assistant. |
| User Profile | Collects age, gender, height, weight and activity level. |
| Food Rules | Defines vegetarian preferences and allowed ingredients. |
| Requirements | Specifies breakfast, lunch, evening snack and dinner. |
| Health Guidelines | Focuses on balanced nutrition and sustainable weight management. |
| Output Format | Defines a structured 7-day Markdown table. |
| Final Instructions | Ensures completeness, consistency and personalisation. |

## 📊 Expected Output

The reusable prompt generates:

1. **7-Day Meal Plan:** 28 meal entries covering four meals per day.
2. **Portion Sizes:** Approximate quantities in cups, grams and pieces.
3. **Daily Healthy Habits:** Water intake, exercise and sleep guidance.
4. **Weekly Grocery List:** Vegetables, fruits, cereals, pulses and dairy products.
5. **Important Notes:** Portion control, healthy alternatives and meal preparation tips.

## 🚀 How to Use This Project

**Step 1:** Open the project in ChatGPT or your preferred AI assistant.

**Step 2:** Copy the reusable prompt from `meal_plan_prompt.md`.

**Step 3:** Enter the user's personal information:

- Age
- Gender
- Height
- Current Weight
- Activity Level
- Food Preferences
- Dietary Restrictions

**Step 4:** Submit the prompt to ChatGPT.

**Step 5:** Generate the complete 7-day South Indian vegetarian meal plan.

**Step 6:** Save the generated results in `meal_plan_output.md`.
